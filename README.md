# Computational Physics

A collection of my solutions, implementations, and projects from *Computational Physics* by Mark Newman.

The repository is organized by chapter and contains:

* Solutions to the majority of worked examples from the textbook
* Solutions to end-of-chapter problem sets
* Numerical simulations and visualizations
* Independent exploratory projects based on concepts from the book

## Repository Structure

The repository is divided into folders corresponding to individual chapters of the textbook.

Each chapter typically contains:

* Worked examples
* Problem set solutions
* Supporting scripts and utilities
* Visualizations and simulations where applicable

## Requirements

* Python 3.11
* NumPy
* Matplotlib
* VPython
* Math (Python standard library)

## Installation

Clone the repository:

```bash
git clone https://github.com/parthkrishnani/computational-physics.git
cd computational-physics
```

Install the required packages:

```bash
pip install numpy matplotlib vpython
```

## Running Programs

Run any script directly with Python:

```bash
python chapter-x/script_name.py
```

## Topics Covered

The repository covers a range of computational physics techniques, including:

* Numerical integration
* Gaussian quadrature
* Root finding
* Ordinary differential equations
* Fourier methods
* Monte Carlo techniques
* Chaos and nonlinear dynamics
* Fractals
* Statistical physics simulations
* Computational modeling and visualization

## Purpose

This repository serves as a record of my work while studying computational physics and developing practical scientific programming skills. The goal is not only to complete textbook exercises, but also to build a strong foundation for computational research in physics.
